MADANI ARENA — دليل التشغيل والنشر من هاتف أندرويد
==================================================

ما الموجود في هذا المشروع؟
- واجهة عربية/إنجليزية متجاوبة بأسود وأخضر نيون.
- صفحات رئيسية، بطولات، سكوادات، ترتيب، ولوحة إدارة.
- تسجيل دخول/إنشاء حساب عبر Supabase عند ربطه.
- مخطط قاعدة بيانات SQL مع سياسات RLS أساسية.
- بيانات تجريبية للعرض قبل ربط قاعدة البيانات.

مهم جداً:
هذه نسخة أولية قابلة للتطوير وليست نسخة مطابقة أو تابعة لـ MLN Arena.
لا يوجد نظام دعوات كامل أو تسجيل سكواد في بطولة من الواجهة حتى الآن؛ الجداول الأساسية موجودة
لكن بعض الوظائف تحتاج استكمالاً قبل إطلاقها للجمهور. لا تضع أبداً Supabase service_role key
في ملفات الواجهة. استخدم فقط Project URL و publishable/anon key مع RLS.

الطريقة الأسهل من أندرويد (GitHub + Vercel + Supabase)
------------------------------------------------------

1) أنشئ قاعدة البيانات:
- افتح https://supabase.com من المتصفح وأنشئ حساباً ومشروعاً مجانياً.
- افتح مشروعك ثم SQL Editor ثم New query.
- افتح الملف supabase/schema.sql من ملفات المشروع وانسخ محتواه إلى SQL Editor ثم اضغط Run.
- من Project Settings / API أو Connect انسخ Project URL و publishable key (أو anon key القديم).
- لا تشارك كلمة مرور قاعدة البيانات أو service_role key.

2) ارفع ملفات الموقع إلى GitHub:
- افتح https://github.com وأنشئ مستودعاً جديداً باسم madani-arena.
- ارفع ملفات المشروع وفولدراته مع الحفاظ على نفس البنية. يمكنك رفع الملفات عبر واجهة GitHub على المتصفح.
- لا ترفع ملف .env الحقيقي. ارفع .env.example فقط.

3) انشر الموقع:
- افتح https://vercel.com وسجّل الدخول باستخدام GitHub.
- Add New / Project واختر madani-arena.
- Framework preset: Vite.
- Build command: npm run build
- Output directory: dist
- في Environment Variables أضف:
  VITE_SUPABASE_URL = رابط مشروع Supabase
  VITE_SUPABASE_ANON_KEY = publishable/anon key
- اضغط Deploy. سيعطيك Vercel رابطاً عاماً للموقع.
- كل تحديث ترفعه إلى GitHub سيعيد النشر تلقائياً غالباً.

4) اجعل حسابك مديراً:
- سجّل حساباً من صفحة الموقع بعد ربط Supabase.
- افتح Supabase / SQL Editor.
- اذهب إلى Authentication / Users وانسخ UUID الخاص بحسابك.
- شغّل الأمر التالي مع استبدال UUID:
  insert into public.admins (user_id) values ('YOUR-USER-UUID');
- بعدها سيُسمح لحسابك بإضافة البطولات والنتائج عبر لوحة الإدارة.

5) إعدادات مهمة:
- في Supabase Authentication / URL Configuration أضف رابط Vercel إلى Site URL
  وإلى Redirect URLs إذا طلب ذلك.
- فعّل تأكيد البريد الإلكتروني أو عطّله للتجربة حسب إعدادات المشروع.
- اختبر الموقع بحساب لاعب عادي وحساب مدير قبل الإعلان عنه.
- لا تجعل أي مستخدم مديراً من خلال تعديل واجهة الموقع؛ صلاحيات الإدارة في قاعدة البيانات.

تشغيل محلي (إن كان عندك كمبيوتر):
- انسخ .env.example إلى .env وضع القيم الصحيحة.
- npm install
- npm run dev
- npm run build

المجلدات:
src/App.jsx              الواجهة الرئيسية والصفحات
src/styles.css           التصميم والتجاوب مع الهاتف
src/lib/supabase.js      اتصال Supabase
supabase/schema.sql      الجداول وسياسات الأمان
.env.example             أسماء متغيرات البيئة المطلوبة

خطوات التطوير التالية قبل إطلاق احترافي:
- إكمال صفحة تفاصيل البطولة والتسجيل بها.
- دعوات السكواد برابط خاص وقبول/رفض الأعضاء.
- نظام نقاط قابل للضبط حسب قوانين البطولة.
- لوحة إدارة لإدارة التسجيلات وتعديل النتائج.
- اختبار أمان RLS على جميع الأدوار.
